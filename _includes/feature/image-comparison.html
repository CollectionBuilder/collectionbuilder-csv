{% comment %} Before-After Image Comparison Slider feature, https://github.com/markpbaggett/before-after Adds an interactive comparison of two images stacked on top of each other, with a slider to reveal one or the other (or fade between them using opacity). Uses the web components in "assets/lib/before-after.js". E.G. --> {% include feature/image-comparison.html img1="comp002" img2="comp003" %} Options: - "img1" = first image (shown on the left / top / bottom layer), several options below (required) 1. an objectid of an image item in this collection, e.g. "comp002" 2. a full URL to an external image file, e.g. "https://www.lib.uidaho.edu/digital/images/fluffyclouds.jpg" 3. a relative link to an image file stored in this repository (that is not included in the collection), i.e. "/assets/img/evan.jpg" - "img2" = second image, same options as img1 (required) - "alt1" = alternative text describing img1. Required for accessibility if using an external URL or relative link, automatically filled if using an objectid (optional) - "alt2" = alternative text describing img2 (optional) - "label1" = label displayed on img1. Defaults to the item title for objectids, or "Before" for image links. Give the value false ('label1=false' - no quotes around false) to display no labels (optional) - "label2" = label displayed on img2. Defaults to the item title for objectids, or "After" for image links (optional) - "type" = comparison type, choose from "horizontal" (slider moves left to right), "vertical" (slider moves top to bottom), or "opacity" (top image fades in and out). Default "horizontal" (optional) - "start" = a percentage for starting slider position or opacity, e.g. "50". Default "65" (optional) - "ratio" = use Bootstrap ratio options "21x9", "16x9", "4x3", or "1x1" to set the responsive aspect ratio of the comparison area. Default "4x3" (optional) - "height" = a CSS height for the comparison area, e.g. "600px" or "75vh" or "100%". Overrides "ratio" if set (optional) - "caption" = by default a caption is added linking to the collection items used in the comparison (for objectids only). The caption option allows you to manually add a different caption, or give the value false for none (optional) {%- endcomment -%} {%- assign compare_imgs = include.img1 | append: "|||" | append:
